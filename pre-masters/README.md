# Pre-Master’s Cybersecurity Preparation

This folder contains the compressed 20-day preparation plan and its section READMEs and daily note files.

[Open the full plan](Pre-Cybersecurity.md).

Each study day targets 130 active minutes and 50 minutes of breaks, for 3 hours total.

## Sections

- [Days 1–5 — Foundations, Linux, and networking](day-01-05-foundations-linux-networking/README.md)
- [Days 6–10 — Network tools, operating systems, and lab safety](day-06-10-network-tools-systems/README.md)
- [Days 11–15 — Web security and assessment](day-11-15-web-security-assessment/README.md)
- [Days 16–20 — Validation, forensics, and review](day-16-20-validation-forensics-review/README.md)

## Safety

Practice only on your own systems or in environments where you have explicit authorization. Record uncertainty honestly and do not save credentials or other secrets in notes.
