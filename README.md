# Cybersecurity Master’s Preparation

This repository contains my notes, exercises, scripts, and authorized
lab write-ups from a 40-day cybersecurity preparation program.

## Objectives

- Learn cybersecurity fundamentals
- Become comfortable using Linux
- Understand networking, DNS, TCP/IP, HTTP, and HTTPS
- Practice introductory Nmap and Wireshark usage
- Learn basic web-security concepts
- Improve technical reporting
- Prepare for my cybersecurity master’s program

## Study phases

- [ ] Days 1–7: Cybersecurity fundamentals and Linux
- [ ] Days 8–14: Networking fundamentals
- [ ] Days 15–21: Operating systems and administration
- [ ] Days 22–28: Web fundamentals and web security
- [ ] Days 29–35: Penetration-testing workflow and evidence
- [ ] Days 36–40: Consolidation and master’s preparation

## Ethical and legal boundary

All practical testing documented in this repository is performed only on
systems I own or systems for which I have explicit authorization.

## Repository contents

- `notes/` — explanations written in my own words
- `commands/` — command references
- `lab-writeups/` — authorized practical exercises
- `reports/` — technical findings and assessment reports
- `scripts/` — small learning scripts
- `diagrams/` — network and system diagrams
- `questions/` — subjects that require further research
- `mistakes/` — mistakes and lessons learned
- `templates/` — reusable report and note templates
